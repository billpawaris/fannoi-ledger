# สมุดบัญชีฟันน้อย

สมุดบัญชีรายรับ–รายจ่ายธีมคลินิกทันตกรรมของบิลและ Gym

- **บัญชีส่วนตัว:** ชาร์ตฟันรายวัน 32 ซี่ และกองทุนเป้าหมายที่แสดงเป็นไกด์เทียบสีฟัน VITA
- **ใช้จ่ายร่วม บิล × Gym:** ใครจ่ายเท่าไร ยอดค้างสะสม บิลประจำเดือน และผลัดกันเลี้ยงข้าว
- **เช็กลิสต์ & บัตร:** รายการที่ต้องจ่าย และเตือนวันครบกำหนดชำระบัตรเครดิตบนแถบด้านบน
- **สรุปยื่นภาษี:** แยกเงินได้ตามมาตรา 40 ประมาณการภาษี และดาวน์โหลดไฟล์ Excel

หน้าเว็บเป็นไฟล์ static ไฟล์เดียว (`index.html`) โฮสต์บน GitHub Pages
ข้อมูลเก็บใน Supabase ป้องกันด้วย Row Level Security ให้อ่านและเขียนได้เฉพาะอีเมลที่อยู่ในตาราง `members`

## ติดตั้ง

### 1. Supabase (ฐานข้อมูลและระบบล็อกอิน)
1. สมัครและสร้างโปรเจกต์ใหม่ที่ https://supabase.com (แพ็กเกจฟรีเพียงพอ) เลือก Region เป็น Singapore
2. เปิด **SQL Editor → New query** วางเนื้อหาไฟล์ `supabase/schema.sql`
3. แก้อีเมลในส่วนที่ 5 ของไฟล์เป็นอีเมลของบิลและ Gym แล้วกด **Run**
4. (ไม่บังคับ) รัน `supabase/seed-examples.sql` เพื่อใส่ข้อมูลตัวอย่าง
5. ไปที่ **Authentication → URL Configuration**
   - ตั้ง **Site URL** เป็นที่อยู่เว็บ เช่น `https://<github-username>.github.io/fannoi-ledger/`
   - เพิ่มที่อยู่เดียวกันใน **Redirect URLs**
6. ไปที่ **Project Settings → API** คัดลอก **Project URL** และ **anon public key** ใส่ในไฟล์ `config.js`

> anon key เปิดเผยในหน้าเว็บได้ตามการออกแบบของ Supabase
> ห้ามใส่ **service_role key** ในไฟล์ใดๆ ของ repo นี้

### 2. GitHub Pages
1. push โค้ดขึ้น GitHub (GitHub Pages แบบฟรีต้องใช้ repo แบบ Public ซึ่งเปิดเผยเฉพาะโค้ด ไม่มีข้อมูลการเงินใดๆ อยู่ใน repo)
2. **Settings → Pages → Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main**, โฟลเดอร์ **/ (root)**
3. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<github-username>.github.io/fannoi-ledger/`

### 3. เข้าใช้งาน
1. เปิดเว็บ ใส่อีเมลที่อยู่ในตาราง `members` แล้วกดลิงก์เข้าสู่ระบบในอีเมล
2. บนมือถือ เพิ่มเป็นไอคอนบนหน้าจอได้
   - iPhone: Safari → Share → Add to Home Screen
   - Android: Chrome → ⋮ → Add to Home screen

## โหมดทดลอง
ถ้า `config.js` ยังเป็นค่าตั้งต้น หน้าเว็บจะทำงานในโหมดทดลองและเก็บข้อมูลในเบราว์เซอร์เครื่องนั้นเท่านั้น
